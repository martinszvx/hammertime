# Hammer Time

Hammer Time is a web application designed to connect users with professionals who provide home maintenance and repair services.

The project was developed as an academic software project, focusing on the implementation of a practical service platform.

## Services

The application is focused on the following services:

* Repairs
* Electrical work
* Plumbing
* Furniture assembly
* Painting
* General maintenance
